# ICompras Clientes
#### Microsserviço para o gerenciamento de Clientes no sistema de e-commerce [**ICompras**](https://github.com/Leoo098/icompras-ecommerce).

## Stack Tecnológica
- **Backend**: Java 21, Spring Boot
- **Mensageria**: Apache Kafka
- **Bancos de Dados**: PostgreSQL
- **Container**: Docker
